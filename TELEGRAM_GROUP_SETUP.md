# Настройка бота для работы с группой (вместо канала)

## ✅ Хорошая новость

**Бот полностью совместим с группами!** Используется та же технология invite-ссылок.

## 📊 Разница между каналом и группой

### Канал:
- 📢 Односторонняя связь (только админы пишут)
- 👥 Неограниченное количество подписчиков
- 📊 Статистика просмотров
- 🔕 Подписчики не получают уведомлений о вступлении других

### Группа:
- 💬 Многосторонняя связь (все участники могут писать)
- 👥 До 200 000 участников (супергруппа)
- 💭 Живое общение между участниками
- 🔔 Больше активности и взаимодействия

## 🔧 Что нужно сделать для работы с группой

### 1. Создайте группу (если еще не создана)

1. Откройте Telegram
2. Нажмите "Новая группа"
3. Добавьте название (например, "Закрытый клуб")
4. Нажмите "Создать"

### 2. Преобразуйте в супергруппу (ВАЖНО!)

⚠️ **Обычная группа не поддерживает все функции!**

1. Откройте настройки группы
2. Выберите "Управление группой"
3. Нажмите "История для новых участников"
4. Выберите "Видна" или "Скрыта"
5. Группа автоматически станет супергруппой ✅

### 3. Получите ID группы

#### Способ 1: Через @userinfobot (РЕКОМЕНДУЕТСЯ)
1. Добавьте @userinfobot в группу
2. Отправьте любое сообщение в группу
3. Бот ответит с ID группы (формат: `-100xxxxxxxxxx` или `-xxxxxxxxx`)

#### Способ 2: Через @getidsbot
1. Добавьте @getidsbot в группу
2. Отправьте команду `/start`
3. Скопируйте ID группы

#### Способ 3: Через веб-версию
1. Откройте группу в web.telegram.org
2. Посмотрите на URL: `https://web.telegram.org/k/#-100xxxxxxxxxx`
3. Скопируйте ID из URL

### 4. Добавьте бота в группу как администратора

1. Откройте настройки группы
2. Нажмите "Администраторы"
3. Нажмите "Добавить администратора"
4. Найдите вашего бота
5. Выберите его

### 5. Настройте права бота

**Обязательные права:**
- ✅ **Приглашать пользователей** - для создания invite-ссылок
- ✅ **Удалять сообщения** - для модерации (опционально)
- ✅ **Блокировать пользователей** - для мягкого удаления (опционально)
- ✅ **Закреплять сообщения** - для важных объявлений (опционально)

**Минимально необходимо:**
```
✅ Приглашать пользователей
```

### 6. Обновите конфигурацию бота

#### В файле `.env`:
```env
# Замените ID канала на ID группы
TELEGRAM_CHANNEL_ID=-100xxxxxxxxxx
```

**Примеры ID:**
```env
# Супергруппа (начинается с -100)
TELEGRAM_CHANNEL_ID=-1001234567890

# Обычная группа (начинается с -)
TELEGRAM_CHANNEL_ID=-1234567890
```

### 7. Перезапустите бота

```bash
node bot.js
```

## 🎯 Как это будет работать

### Процесс для пользователя:

1. **Пользователь оплачивает доступ** (2000₽)
2. **Бот создает invite-ссылку** для группы
3. **Пользователь получает ссылку** в личных сообщениях
4. **Пользователь переходит по ссылке** и присоединяется к группе
5. **Пользователь видит всю историю** (если настроено)

### При истечении подписки:

1. **Бот помечает пользователя** как удаленного (мягкое удаление)
2. **Пользователь остается в группе** но помечен неактивным
3. **Пользователь получает уведомление** о необходимости продления

### При повторной оплате:

1. **Бот автоматически восстанавливает доступ**
2. **Пользователь получает уведомление** о восстановлении
3. **Создается новая invite-ссылка** (на случай, если вышел)

## ⚠️ Важные отличия при работе с группой

- Назначьте **дополнительных модераторов**
- Создайте **правила группы**

## 🔍 Проверка совместимости

Бот проверяет ID при запуске:

```javascript
// В bot.js строка ~305-311
if (!config.telegram.channelId.toString().startsWith('-10') && 
    !config.telegram.channelId.toString().startsWith('-20') &&
    !config.telegram.channelId.toString().startsWith('-100')) {
    console.log('❌ ID неправильный');
}
```

**Поддерживаемые форматы ID:**
- `-10xxxxxxxxx` - супергруппа
- `-20xxxxxxxxx` - канал
- `-100xxxxxxxxxx` - супергруппа (новый формат)
- `-xxxxxxxxx` - обычная группа
