## 🚀 Как использовать с группой

### Шаг 1: Получите ID группы

#### Через @userinfobot (РЕКОМЕНДУЕТСЯ):
1. Добавьте @userinfobot в группу
2. Отправьте сообщение в группу
3. Скопируйте ID группы

#### Через @getidsbot:
1. Добавьте @getidsbot в группу
2. Отправьте `/start`
3. Скопируйте ID

### Шаг 2: Обновите конфигурацию

В файле `.env`:
```env
# Для супергруппы
TELEGRAM_CHANNEL_ID=-1001234567890

# Для обычной группы  
TELEGRAM_CHANNEL_ID=-123456789

# Для канала
TELEGRAM_CHANNEL_ID=-2012345678
```

### Шаг 3: Добавьте бота в группу

1. Откройте группу
2. Добавьте бота
3. Сделайте бота администратором
4. **Обязательно** дайте право "Приглашать пользователей"

### Шаг 4: Запустите бота

```bash
node bot.js
```

**Проверьте логи:**
```
Channel ID from config: -100xxxxxxxxxx
✅ Chat ID format is valid (type: supergroup)
Using invite link approach for supergroup -100xxxxxxxxxx
✅ Subscription checker started
Telegram Bot started successfully!
```

## 🔍 Автоматическое определение типа

Бот автоматически определяет тип чата при предоставлении доступа:

```javascript
if (chatId.startsWith('-100')) {
    chatType = 'supergroup';  // Супергруппа
} else if (chatId.startsWith('-20')) {
    chatType = 'channel';      // Канал
} else if (chatId.startsWith('-')) {
    chatType = 'group';        // Обычная группа
}
```

## ⚠️ Рекомендации для группы

### 1. Преобразуйте в супергруппу
Обычная группа → Супергруппа:
- Откройте настройки группы
- "История для новых участников" → Выберите любой вариант
- Группа автоматически станет супергруппой

### 2. Настройте модерацию
- Включите медленный режим (30 сек - 5 мин)
- Создайте правила группы
- Назначьте модераторов

### 3. Настройте права участников
- Отправка сообщений: ✅
- Отправка медиа: ✅ (опционально)
- Отправка стикеров: ✅ (опционально)
- Добавление участников: ❌ (только админы)
