# Настройка Prodamus для Telegram бота

## ❌ Проблема: "Неизвестный запрос"

Эта ошибка возникает, когда Prodamus не может проверить подпись или параметры не соответствуют ожидаемому формату.

## 🔧 Решение

### 1. Получите правильный секретный ключ

1. **Войдите в личный кабинет Prodamus**: https://prodamus.ru
2. **Перейдите в настройки магазина**
3. **Найдите раздел "API" или "Интеграция"**
4. **Скопируйте секретный ключ** (не тестовый!)

### 2. Обновите файл .env

Замените тестовый ключ на реальный:

```env
# Prodamus Configuration
PRODAMUS_SECRET_KEY=ваш_реальный_секретный_ключ_из_prodamus
PRODAMUS_LINK_TO_FORM=https://ваш_домен.payform.ru/pay
PRODAMUS_WEBHOOK_URL=https://ваш_домен.com/webhook/prodamus
```

### 3. Проверьте настройки магазина

В личном кабинете Prodamus убедитесь, что:

- ✅ **Домен магазина** указан правильно
- ✅ **Webhook URL** настроен корректно
- ✅ **Секретный ключ** активен
- ✅ **Форма оплаты** создана и активна

### 4. Тестирование

Создайте тестовый файл `test-real-key.js`:

```javascript
const config = require('./config');
const ProdamusService = require('./services/prodamusService');

console.log('=== Тест с реальным ключом ===');
console.log('Secret key:', config.prodamus.secretKey);
console.log('Link to form:', config.prodamus.linkToForm);

const paymentData = ProdamusService.createPaymentData(123456789, 500.00, 'Тест');
const paymentLink = ProdamusService.createPaymentLink(paymentData);

console.log('Payment link:', paymentLink);

// Проверяем наличие подписи
const url = new URL(paymentLink);
const signature = url.searchParams.get('signature');
console.log('Signature present:', !!signature);
console.log('Signature length:', signature ? signature.length : 0);
```

Запустите тест:
```bash
node test-real-key.js
```

### 5. Проверьте URL формы

Убедитесь, что ссылка на форму правильная:

- ✅ Формат: `https://ваш_домен.payform.ru/pay`
- ✅ Домен соответствует настройкам в Prodamus
- ✅ Форма активна и доступна

## 🚨 Частые проблемы

### Проблема: Неверный секретный ключ

**Симптомы:** Ошибка "Неизвестный запрос"

**Решение:**
1. Получите правильный ключ в личном кабинете Prodamus
2. Обновите `PRODAMUS_SECRET_KEY` в `.env`
3. Перезапустите бота

### Проблема: Неправильный домен

**Симптомы:** Ошибка авторизации

**Решение:**
1. Проверьте домен в настройках Prodamus
2. Обновите `PRODAMUS_LINK_TO_FORM` в `.env`
3. Убедитесь, что домен соответствует настройкам

### Проблема: Неактивная форма

**Симптомы:** Ошибка доступа к форме

**Решение:**
1. Проверьте, что форма оплаты активна
2. Убедитесь, что форма доступна по указанному URL
3. Проверьте настройки формы в Prodamus
