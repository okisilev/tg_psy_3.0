// Проверяем, что ID канала правильный (начинается с -10, -20 или -100)
if (!config.telegram.channelId.toString().startsWith('-10') && 
    !config.telegram.channelId.toString().startsWith('-20') &&
    !config.telegram.channelId.toString().startsWith('-100')) {
    console.log('❌ ID канала неправильный');
    throw new Error('Invalid channel ID format');
}

## 🎯 Как получить ID канала

### **Способ 1: Через бота @userinfobot**
1. Добавьте @userinfobot в канал
2. Отправьте сообщение в канал
3. Скопируйте ID из ответа бота

### **Способ 2: Через веб-версию**
1. Откройте канал в web.telegram.org
2. Посмотрите на URL
3. Скопируйте ID из URL

### **Способ 3: Через мобильное приложение**
1. Откройте канал в Telegram
2. Нажмите на название канала
3. Выберите "Информация о канале"
4. Найдите "Идентификатор"

## 🔐 Настройка прав бота

### **Обязательные права:**
- ✅ **Приглашать пользователей** - для создания invite links
- ✅ **Исключать участников** - для удаления пользователей
- ✅ **Управлять чатом** - для управления каналом
- ✅ **Добавлять участников** - для прямого добавления

### **Как настроить:**
1. Откройте канал в Telegram
2. Перейдите в "Управление каналом"
3. Выберите "Администраторы"
4. Добавьте бота как администратора
5. Включите все необходимые права
