# Решение проблемы "Неизвестный запрос" в Prodamus

## 🔍 Диагностика проблемы

Если вы получаете ошибку "Неизвестный запрос" в Prodamus, это означает, что:

1. ❌ Отсутствует параметр `signature` в URL
2. ❌ Неверная подпись HMAC
3. ❌ Неправильные параметры запроса

## ✅ Решение

### 1. Проверьте конфигурацию

Убедитесь, что в файле `.env` указаны правильные данные:

```env
# Prodamus Configuration
PRODAMUS_SECRET_KEY=ваш_реальный_секретный_ключ_из_prodamus
PRODAMUS_LINK_TO_FORM=https://ваша_форма.payform.ru/pay
```

### 2. Перезапустите бота

```bash
# Остановите бота (Ctrl+C)
# Затем запустите снова
npm start
```

### 3. Проверьте логи

При создании платежной ссылки в логах должно быть:

```
✅ Конфигурация корректна!
Telegram Bot started successfully!
Server running on port 3000
```

### 4. Тестирование

Создайте тестовый файл `test-payment.js`:

```javascript
const config = require('./config');
const ProdamusService = require('./services/prodamusService');

const paymentData = ProdamusService.createPaymentData(123456789, 500.00, 'Тест');
const paymentLink = ProdamusService.createPaymentLink(paymentData);

console.log('Payment link:', paymentLink);

// Проверяем наличие подписи
const url = new URL(paymentLink);
const signature = url.searchParams.get('signature');
console.log('Signature present:', !!signature);
```

Запустите тест:
```bash
node test-payment.js
```

### 5. Проверьте URL

Правильный URL должен содержать параметр `signature` в конце:

```
https://dashastar.payform.ru/pay?do=pay&sys=telegram&...&signature=abc123...
```

## 🚨 Частые проблемы

### Проблема: Подпись отсутствует в URL

**Причина:** Неправильная конфигурация или старый код

**Решение:**
1. Убедитесь, что используете актуальный код
2. Проверьте файл `.env`
3. Перезапустите бота

### Проблема: Неверная подпись

**Причина:** Неправильный секретный ключ

**Решение:**
1. Получите правильный секретный ключ в личном кабинете Prodamus
2. Обновите `PRODAMUS_SECRET_KEY` в `.env`
3. Перезапустите бота

### Проблема: Неправильные параметры

**Причина:** Неверная ссылка на форму

**Решение:**
1. Проверьте ссылку на форму в Prodamus
2. Обновите `PRODAMUS_LINK_TO_FORM` в `.env`
3. Убедитесь, что ссылка заканчивается на `/pay`
