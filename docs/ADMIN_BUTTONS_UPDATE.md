# ✅ Добавлены новые кнопки для администраторов

## 🎯 Что добавлено

### 👑 **Кнопка "Панель администратора"**
- ✅ Доступна **только администраторам** в меню `/start`
- ✅ Открывает полную панель администратора
- ✅ Включает все административные функции

### 👥 **Кнопка "Без доступа"**
- ✅ Показывает пользователей с истекшей подпиской
- ✅ Отображает дату истечения и количество дней назад
- ✅ Показывает статус (заблокирован/неактивен)
- ✅ Разбивает длинные списки на части

## 🔧 Техническая реализация

### **Новые функции:**

#### 1. **`showAdminPanel(chatId, userId)`**
- Проверяет права администратора
- Показывает панель с кнопками
- Обрабатывает ошибки

#### 2. **`showNoAccessUsers(chatId, userId)`**
- Получает пользователей без доступа
- Форматирует информацию
- Разбивает длинные сообщения

#### 3. **`getNoAccessUsers()`**
- SQL запрос для получения пользователей с истекшей подпиской
- Сортировка по дате истечения
- Включает статус блокировки

#### 4. **`splitMessage(message, maxLength)`**
- Разбивает длинные сообщения на части
- Предотвращает ошибки Telegram API
- Сохраняет форматирование

### **SQL запрос для пользователей без доступа:**
```sql
SELECT u.telegram_id, u.username, u.first_name, u.last_name, 
       s.end_date, u.is_banned, u.has_access
FROM users u
LEFT JOIN subscriptions s ON u.telegram_id = s.telegram_id
WHERE (u.has_access = FALSE OR s.end_date < datetime('now'))
ORDER BY s.end_date DESC
```

## 📊 Информация о пользователях без доступа

### **Что показывается:**
- **ID пользователя** - Telegram ID
- **Username** - @username или "не указан"
- **Дата истечения** - когда истекла подписка
- **Дней назад** - сколько дней прошло с истечения
- **Статус** - заблокирован или неактивен

### **Сортировка:**
- По дате истечения (новые сверху)
- Показываются только пользователи без доступа
- Включаются заблокированные пользователи
