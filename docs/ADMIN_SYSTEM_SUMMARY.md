## 🔧 Как настроить

### 1. Добавить ID администратора

Отредактируйте функцию `isAdmin()` в `bot.js` (строка ~458):

```javascript
isAdmin(userId) {
    const adminIds = [
        431292182,  // Основной администратор
        123456789,  // Добавьте сюда ID нового админа
        // Добавьте сюда ID других администраторов
    ];
    return adminIds.includes(userId);
}
```

### 2. Получить ID пользователя

**Способ 1: Через @userinfobot**
1. Добавьте [@userinfobot](https://t.me/userinfobot) в группу
2. Пользователь отправит сообщение
3. Скопируйте ID из ответа бота

**Способ 2: Через @getidsbot**
1. Добавьте [@getidsbot](https://t.me/getidsbot) в группу
2. Пользователь отправит `/start`
3. Скопируйте ID из ответа

## 🎮 Как использовать

### Для администратора:

#### 1. Проверить права:
```
/checkadmin
```
**Ответ:** "👑 Вы администратор! У вас есть полные права."

#### 2. Открыть панель администратора:
```
/admin
```
**Показывает кнопки:**
- 📊 Статистика
- 👥 Список пользователей  
- 🔍 Найти пользователя
- ⚙️ Настройки

#### 3. Обычное взаимодействие:
- Отправляет `/start` → "👑 Вы администратор! У вас есть полный доступ к сообществу."
- Нажимает "Оплатить" → "👑 Вы администратор! Вам не нужно оплачивать доступ..."
- Нажимает "Проверить оплату" → "👑 Вы администратор! Вам не нужно проверять платежи..."

## ✨ Что происходит для администраторов

### Вместо обычного процесса:
```
Обычный пользователь:
```

## 📊 Административные функции

### 📊 Статистика
Показывает:
- Общее количество пользователей
- Пользователи с доступом
- Пользователи без доступа
- Общее количество платежей
