### 1. ✅ Мягкое удаление и восстановление доступа

**Проблема:**
- При истечении подписки пользователи удалялись из канала (жесткий бан)

## 📋 Чеклист перед запуском

### Обязательно выполнить:

- [ ] **Создать резервную копию БД:**
  ```bash
  cp bot.db bot.db.backup
  ```

- [ ] **Запустить миграцию БД:**
  ```bash
  node migration-add-is-banned.js
  ```

- [ ] **Проверить результат миграции:**
  ```bash
  sqlite3 bot.db "PRAGMA table_info(users);"
  ```
  Должно быть поле `is_banned`

### После миграции:

- [ ] **Запустить бота:**
  ```bash
  node bot.js
  ```

- [ ] **Проверить логи запуска** - не должно быть ошибок

- [ ] **Протестировать команду `/start`:**
  - Должна быть цена 2000₽
  - Должна быть кнопка "Индивидуальная консультация"

- [ ] **Проверить кнопку WhatsApp** - должен открываться чат с +79025158278

- [ ] **Проверить создание платежа** - сумма должна быть 2000₽
